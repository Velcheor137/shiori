### Добавлено
- Вход в аккаунт RanobeLib через страницу сайта, зашифрованное хранение сессии.
- Каталог, главная с «Продолжить чтение», карточка тайтла, список глав с переводчиками и закреплённым переводом.
- Читалка в стиле RanobeLib: полный экран, плавающая панель, копирование текста, полоса прочитанного, большие настройки.
- Режим текста «Оригинал / Литературный» (тире для реплик, «ёлочки» для мыслей).
- Комментарии всех переводов главы: картинки, ответы, оценки, сортировка, отправка.
- Скачивание глав по диапазонам и офлайн-чтение.
- Закладки в тексте, библиотека из аккаунта, синхронизация прогресса (по желанию).
- Тёмная и светлая темы, иконка приложения.
- Сборка и релизы через GitHub Actions.
- Уведомления: новые главы и ответы на комментарии; ответ открывается окном комментариев главы с прокруткой к нужному месту.
